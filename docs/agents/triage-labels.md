# Triage labels

The skills use five canonical triage roles. This file maps those roles to the label strings in this repo's issue tracker.

| Canonical role    | Tracker label     | Meaning                                    |
| ----------------- | ----------------- | ------------------------------------------ |
| `needs-triage`    | `needs-triage`    | A maintainer must evaluate the issue       |
| `needs-info`      | `needs-info`      | Waiting for information from the reporter  |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent     |
| `ready-for-human` | `ready-for-human` | Requires human implementation              |
| `wontfix`         | `wontfix`         | Will not be implemented                    |

When a skill mentions a canonical role, use the corresponding tracker label from this table.

Edit the tracker label column if the repository's vocabulary changes.
